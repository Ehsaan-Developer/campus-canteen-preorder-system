# Campus Canteen Pre‑Order System

A web-based system that allows students to pre‑order canteen food, select pickup time, and collect orders without waiting in long queues.  
Includes Admin Panel and Python-based sales analysis.

## Features

- Menu from database (MySQL)
- Add to cart + quantity management (JavaScript)
- Checkout (name + pickup time)
- Orders saved in database (PHP + MySQL)
- Track order status (Pending/Preparing/Ready)
- Admin: manage orders + products (CRUD)
- Python analytics: top items + combos (JSON)

## Tech Stack

- HTML, CSS, JavaScript
- PHP
- MySQL (phpMyAdmin)
- Python 3 (mysql-connector)

## How to Run (XAMPP)

1. Start Apache + MySQL in XAMPP
2. Put project folder in: `xampp/htdocs/canteen_project`
3. Import database: `database/canteen_db.sql` into `canteen_db`
4. Open: `[http://localhost/canteen_project/menu.php`
